# SPbU Timetable → ICS

Автоматический календарь из расписания СПбГУ.

Проект получает актуальное расписание с `timetable.spbu.ru`, преобразует его в `.ics` и автоматически обновляет календарь через GitHub Actions.

Можно выбрать свою учебную группу, нужные элективы и факультативы. Отменённые занятия в календарь не добавляются.

После настройки получается постоянная ссылка на календарь, которую можно добавить в Apple Calendar, Google Calendar, Outlook и другие приложения с поддержкой iCalendar.

## Как это работает

Проект:

- загружает расписание выбранной группы с `timetable.spbu.ru`;
- получает название предмета, время, преподавателя и аудиторию;
- исключает занятия, отмеченные на сайте СПбГУ как отменённые;
- оставляет только выбранные элективы и факультативы;
- создаёт файл `docs/schedule.ics`;
- автоматически проверяет расписание каждый час;
- публикует календарь через GitHub Pages.

После первоначальной настройки вручную обновлять календарь не нужно.

# Настройка своего расписания

## 1. Сделайте Fork репозитория

Нажмите кнопку **Fork** в верхней части страницы этого репозитория.

GitHub создаст копию проекта в вашем аккаунте.

Рекомендуется оставить имя репозитория:

```text
spbu_timetable_to_ics
```

---

## 2. Найдите свою группу

Откройте:

https://timetable.spbu.ru

Найдите свою учебную группу и откройте её расписание.

Ссылка будет выглядеть примерно так:

```text
https://timetable.spbu.ru/GSOM/StudentGroupEvents/Primary/474266
```

Здесь:

```text
GSOM
```

— код подразделения, а

```text
474266
```

— ID учебной группы.

Эти значения понадобятся для настройки.

---

## 3. Настройте `config.json`

Откройте в своём Fork файл:

```text
config.json
```

Нажмите кнопку редактирования и замените настройки на свои.

Пример:

```json
{
  "group_id": 474266,
  "group_name": "24.Б02-вшм",
  "division": "GSOM",
  "electives": [
    "Электив. Теория игр"
  ],
  "facultatives": [],
  "months_ahead": 8,
  "timezone": "Europe/Moscow",
  "calendar_name": "СПбГУ — 24.Б02-вшм"
}
```

### Параметры

`group_id` — ID вашей группы из ссылки на расписание.

`group_name` — название группы.

`division` — код подразделения из ссылки на расписание.

`electives` — элективы, которые должны попасть в календарь.

`facultatives` — факультативы, которые должны попасть в календарь.

`months_ahead` — на сколько месяцев вперёд загружать расписание.

`timezone` — часовой пояс календаря.

`calendar_name` — название календаря, которое будет отображаться в приложении.

Если элективы не нужны:

```json
"electives": []
```

Если факультативы не нужны:

```json
"facultatives": []
```

Названия элективов и факультативов нужно указывать так, как они называются в расписании СПбГУ.

После изменения нажмите **Commit changes**.

---

## 4. Разрешите GitHub Actions обновлять календарь

В своём репозитории откройте:

```text
Settings → Actions → General
```

Найдите раздел:

```text
Workflow permissions
```

Выберите:

```text
Read and write permissions
```

и нажмите **Save**.

Это необходимо, чтобы автоматическое обновление могло сохранять новый `schedule.ics` в репозиторий.

---

## 5. Запустите календарь

Откройте вкладку:

```text
Actions
```

Выберите workflow:

```text
Update calendar
```

и нажмите:

```text
Run workflow
```

После успешного запуска в папке:

```text
docs
```

появится или обновится файл:

```text
schedule.ics
```

В дальнейшем GitHub Actions будет автоматически проверять расписание каждый час.

---

## 6. Включите GitHub Pages

Откройте:

```text
Settings → Pages
```

В разделе **Build and deployment** выберите:

```text
Source: Deploy from a branch
```

Затем:

```text
Branch: main
Folder: /docs
```

и нажмите **Save**.

После публикации GitHub покажет адрес вашего сайта.

Если ваш GitHub username:

```text
username
```

а репозиторий называется:

```text
spbu_timetable_to_ics
```

то адрес календаря обычно будет иметь вид:

```text
https://username.github.io/spbu_timetable_to_ics/schedule.ics
```

Используйте адрес, который GitHub показывает в **Settings → Pages**.

# Подключение календаря

Важно добавлять `.ics` именно как **подписной календарь**, а не просто один раз импортировать файл.

При подписке приложение сможет получать последующие изменения расписания.

## Apple Calendar на iPhone и iPad

Откройте:

```text
Настройки → Приложения → Календарь → Учетные записи календаря
```

Добавьте новую учётную запись и выберите подписной календарь.

Вставьте ссылку на:

```text
https://username.github.io/spbu_timetable_to_ics/schedule.ics
```

и сохраните календарь.

## Apple Calendar на Mac

Откройте приложение **Календарь**.

Выберите:

```text
Файл → Новая подписка на календарь
```

Вставьте ссылку на `schedule.ics` и подтвердите добавление.

## Google Calendar

Откройте Google Calendar в браузере.

В разделе **Другие календари** выберите:

```text
+ → Добавить по URL
```

Вставьте ссылку на `schedule.ics`.

## Другие приложения

Используйте функцию добавления календаря по URL или подписки на iCalendar / ICS.

# Обновление расписания

GitHub Actions автоматически запускает генерацию календаря каждый час.

Если в расписании СПбГУ:

- изменилось время занятия;
- изменилась аудитория;
- изменился преподаватель;
- появилось новое занятие;
- занятие было отменено,

следующая генерация обновит `schedule.ics`.

Отменённые занятия не включаются в итоговый календарь.

Обратите внимание: проект может обновить файл каждый час, но само календарное приложение может проверять подписной календарь реже. Частота обновления Apple Calendar, Google Calendar или другого клиента зависит от самого приложения.

```text
config.json
```

# Локальный запуск

Для работы через GitHub локальный запуск не требуется.

Если нужно запустить проект на компьютере, понадобится Python 3.11 или новее.

```bash
git clone https://github.com/YOUR_USERNAME/spbu_timetable_to_ics.git
cd spbu_timetable_to_ics

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python setup.py
python generate_calendar.py
```

На Windows активация виртуального окружения:

```powershell
.venv\Scripts\activate
```

`setup.py` позволяет настроить группу, элективы и факультативы через интерактивный мастер.

Готовый календарь будет сохранён в:

```text
docs/schedule.ics
```

# Важно

Проект не является официальным сервисом Санкт-Петербургского государственного университета.

Данные берутся с публичного сайта расписания:

https://timetable.spbu.ru

Корректность календаря зависит от данных, опубликованных в официальном расписании СПбГУ.

Если расписание на сайте ещё не опубликовано на будущий период, соответствующие занятия появятся в календаре после их публикации и следующего автоматического обновления.
